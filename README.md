# SQL + Power BI E-Commerce Analytics Dashboard

## Project Overview

This is an end-to-end Business Intelligence project developed using MySQL, SQL, Power BI, and DAX. The project analyses e-commerce business data to generate actionable insights through interactive dashboards.
